Daigoro SNS Manager

What is Daigoro SNS Manager?

Daigoro SNS Manager is an internal tool developed and used by moairo Inc. to support the operation of the Company's own official social media accounts. It is not a public product and is not available to external users or other businesses.

Key Features

  • Organizes video content created internally for posting to the Company's own official social media accounts.
  • Connects to TikTok using TikTok Login Kit and the Content Posting API to deliver prepared videos to the Company's own TikTok account for review.

Purpose of TikTok Integration

Daigoro SNS Manager uses the TikTok Content Posting API (video.upload) only to deliver video files, created internally by moairo Inc., to the inbox (draft) of the Company's own, already-authorized TikTok account. This integration does not publish any content automatically. Every post is reviewed and published manually, at the sole discretion of an authorized staff member, directly within the TikTok app. Daigoro SNS Manager does not use TikTok's Direct Post feature and does not publish content on behalf of any user without manual review.

Operator

Daigoro SNS Manager is operated by moairo Inc. for internal use only.
